# Bureau

Bureau est un plugin de [Boite](https://github.com/mtsu-dev/boite). Il fait deux choses :

- il montre les agents de Boite comme de petits employés dans un immeuble, un étage par projet, dans une page locale ouverte dans le panneau de Boite ;
- il donne aux agents une organisation de travail à trois étages : un chef de projet, des responsables de service (managers) et des agents.

Version actuelle : 0.1.0. Licence MIT.
